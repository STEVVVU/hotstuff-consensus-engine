# P08 work record

Outcome is the complete inherited engine plus a bounded adversarial workbench, preserved provenance and repeatable local evidence. Constraints are one owner, no remote hosts, no cloud, no GPU, no privilege changes, no secret files or publication. Acceptance is actual signed QCs, distinct quorum participants, initial leader failure/recovery, quorum absence, honest commit agreement, duplicate client execution, real loopback replicas/client and a sensitive oracle.

Feature workflow followed source inspection, baseline reproduction, verification onboarding, typed journey/commit records, bounded implementation, runtime drive and review. Optional how/architect panels and nested delegation were skipped under the user's one-owner override. Opening a PR and publishing were excluded by the bounded assignment.

Throughput checkpoint. Blocking steps were license/source inspection and build baseline. Independent workstreams were not split because core certificate and harness evidence changes require one consistent revision. Mutable state is isolated to a fresh scratch directory and ephemeral keys. The smallest safe decomposition is one owner for the adapter and two focused upstream fixes.

Model the Domain shaped the named journey and commit evidence records. Ponytail shaped reuse of the actual upstream CLI, Twins executor, signature primitives and command executor instead of a second consensus implementation. No performance benchmark was added. Parent-agent and independent reviews remain external gates before publication.
